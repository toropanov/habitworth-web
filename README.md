## 📱 HabitWorth

**HabitWorth** is an Android habit tracker that turns daily actions into progress toward meaningful personal goals. Assign each habit a virtual reward, build streaks, set reminders, and watch your virtual savings jar grow toward a book, course, trip, or anything else you want to work toward.

The app is private by design: no account is required, and habits, goals, and history stay on the device. All in-app amounts are virtual — HabitWorth is not a banking, payment, or investment service.
